▌_ Sentinel — DAO Proposal Security Agent

An autonomous agent that audits DAO governance proposals and the smart-contract code they execute — before the vote. Static analysis + governance risk + privacy checks, fully deterministic, no API key, no wallet, no server. Built for the Terminal 3 Build+Scale Agent Micro Grant (DoraHacks).

1 · Proposal

Proposal JSON shape: { id, title, description, proposerProposals, treasuryBalance, requestedAmount, timelockSeconds, executor: {type, signers}, targets: [{to, value, calldata, description, toIsContract}], claimsNoCodeChange, collectsUserData, dataDescription, code: [{file, source}] }. Everything runs locally in your browser — nothing is uploaded.

2 · Agent verdict

Pick a fixture or paste a proposal, then press Analyse proposal.
Sentinel will score it 0–100 and list every finding with evidence.
Sentinel is deterministic, rule-based analysis — a second pair of eyes, not a substitute for a human audit. Source & tests: github.com/dimasamirul1899-afk/terminal3-sentinel · MIT
